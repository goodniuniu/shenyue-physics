## 第一部分：题目（共 30 题，建议用时 20 分钟）

### A. 判断题（√/×，每题一句话）

1. 动量是矢量，方向与速度方向相同。
2. 物体速度大小不变，动量一定保持不变。
3. 与位移垂直的力，对物体的冲量为零。
4. 动量变化量是矢量差，不能直接算数值之差。
5. 小球撞墙后原速反弹，动量变化量为零。
6. 动量定理中的 F 指的是物体所受的合外力。
7. F-t 图线与时间轴围成的面积等于冲量。
8. 系统动量守恒的条件是系统合外力为零。
9. 碰撞、爆炸瞬间内力远大于外力时，可近似认为动量守恒。
10. 某方向上合外力为零，则系统的总动量守恒。
11. 系统动量守恒，机械能也一定守恒。
12. 完全非弹性碰撞中动能损失最大。
13. 等质量两球发生弹性正碰后交换速度。
14. 碰撞后系统的动能可能比碰撞前多。
15. 爆炸与反冲过程动量守恒，但动能反而增加。
16. 人船模型中，人前进船后退，位移大小与质量成反比。
17. 人船模型公式中的位移是相对于船的位移。
18. 子弹打入放在光滑地面上的木块，系统动量守恒、机械能守恒。
19. 木块固定在地面上时，子弹打木块过程系统动量守恒。
20. 验证动量守恒实验中，斜槽末端必须保持水平。

28. 人船模型位移关系式 $m_1 x_1 = $ ______。

## 第二部分：答案与一句话解析

### A. 判断题

| 题 | 答案 | 一句话解析 |
|----|------|-----------|
| 1 | √ | 动量方向 = 速度方向 |
| 2 | × | 速度方向变，动量就变（如匀速圆周运动） |
| 3 | × | 冲量 $I=Ft$ 与位移无关；有力有时间就有冲量（二中卷题 1 原型） |
| 4 | √ | 必须带方向（正交分解或正负号） |
| 5 | × | $\Delta p = -2mv$，方向反了是"翻倍"不是"归零" |
| 6 | √ | 代入某一个分力是经典错误 |
| 7 | √ | 面积即冲量，轴下方面积记负 |
| 8 | √ | 合外力为零是全过程守恒的严格条件 |
| 9 | √ | 内力≫外力时该瞬间近似守恒 |
| 10 | × | 只是**该方向**动量守恒，总动量未必 |
| 11 | × | 完全非弹性碰撞动量守恒但机械能不守恒 |
| 12 | √ | 共速时相对动能全部损失 |
| 13 | √ | 弹性碰撞特例，选择题秒杀点 |
| 14 | × | 碰撞动能不增；动能增加的是爆炸/反冲 |
| 15 | √ | 化学能等其他形式能转化而来 |
| 16 | √ | $m_1x_1=m_2x_2$，质量大的动得少 |
| 17 | × | 位移相对**地面**；相对位移才是 $x_1+x_2$ |
| 18 | × | 动量守恒，但机械能不守恒（生热 $Q=f s_{相对}$） |
| 19 | × | 墙/地对木块施力，是外力 → 不守恒 |
| 20 | √ | 末端水平保证小球做平抛、射程正比于速度 |

### B. 填空题

| 题 | 答案 |
|----|------|
| 21 | $mv$；$Ft$ |
| 22 | $F_{合}\,t = mv' - mv$ |
| 23 | 合外力为零；内力≫外力（瞬间守恒）；某方向合外力为零（单方向守恒） |
| 24 | 动量；动能 |
| 25 | $\dfrac{m_1v_1+m_2v_2}{m_1+m_2}$ |
| 26 | 动量守恒；动能不增；速度合理（不二次碰撞） |
| 27 | 相对位移 |
| 28 | $m_2 x_2$ |
| 29 | $\dfrac{(m_1-m_2)v_1}{m_1+m_2}$ |
| 30 | $m_1\cdot\overline{OM} + m_2\cdot\overline{ON}$ |

## 第一部分：题目（共 30 题，建议用时 20 分钟）

### A. 判断题（√/×，每题一句话）

1. 简谐运动中，回复力与位移成正比、方向相反。
2. 单摆的周期与摆球质量、振幅有关。
3. 振子经过平衡位置时，速度最大、加速度为零。
4. 受迫振动的频率等于物体的固有频率。
5. 驱动力频率等于固有频率时，振幅最大（共振）。
6. 振动图像的横轴是位置 x。
7. 波传播时，介质中的质点随波一起向前迁移。
8. 波速由介质决定，与波源的频率无关。
9. 两列波干涉时，加强点的位置随时间移动。
10. 到两波源路程差为波长整数倍的点是振动减弱点。
11. 障碍物尺寸与波长相当或更小时，衍射现象明显。
12. 波源靠近观察者时，观察者接收到的频率变高。
13. 光从空气射入水中，频率不变、波长变短。
14. 折射率越大的光，在介质中传播速度越大。
15. 紫光比红光的折射率大、临界角小。
16. 光从空气射入玻璃时，可能发生全反射。
17. 肥皂膜上的彩色条纹是光的衍射现象。
18. 光的偏振现象证明光是纵波。
19. 双缝干涉条纹间距与光的波长成正比。
20. 双缝干涉实验中换用蓝光后，条纹变宽。

### B. 填空题（写关键词/公式）

21. 单摆周期公式 $T = $ ______。
22. 波速、波长、频率的关系 $v = $ ______。
23. 折射定律 $n = $ ______；折射率与光速的关系 $n = $ ______。
24. 全反射临界角公式 $\sin C = $ ______。
25. 全反射的两个条件：______、______。
26. 双缝干涉条纹间距公式 $\Delta x = $ ______。
27. 干涉加强条件：路程差 $\delta = $ ______；减弱条件 $\delta = $ ______。
28. 双缝干涉测波长实验的器材顺序（光源后）：滤光片 → ______ → ______ → 光屏。
29. 色散链条：频率越高 → 折射率越______ → 介质中速度越______ → 临界角越______。
30. 测第 1 条到第 n 条亮纹的间距时，条纹间隔数 = ______。

## 第二部分：答案与一句话解析

### A. 判断题

| 题 | 答案 | 一句话解析 |
|----|------|-----------|
| 1 | √ | $F=-kx$ 是简谐运动的判据 |
| 2 | × | $T=2\pi\sqrt{l/g}$ 只与摆长、g 有关 |
| 3 | √ | 平衡位置：速度最大、回复力与加速度为零 |
| 4 | × | 受迫振动频率 = **驱动力**频率，与固有频率无关 |
| 5 | √ | 共振条件，大棚阻尼器反而要避开它 |
| 6 | × | 振动图横轴是**时间 t**；横轴是 x 的是波动图 |
| 7 | × | 质点只在原地振动，波形在迁移（"照片在传、人不动"） |
| 8 | √ | 同一介质波速恒定，频率变则波长跟着变 |
| 9 | × | 加强/减弱位置**固定不动**，这是干涉稳定图样的含义 |
| 10 | × | $\delta=n\lambda$ 是**加强**点；半波长奇数倍才减弱 |
| 11 | √ | 明显衍射条件：尺寸 ≈ λ 或更小 |
| 12 | √ | 多普勒效应：靠近变高、远离变低 |
| 13 | √ | 频率由光源决定不变；$v$ 变小故 $\lambda$ 变短 |
| 14 | × | $v=c/n$，n 大则 v **小** |
| 15 | √ | $n_紫>n_红$，$\sin C=1/n$ 故紫光临界角小、更易全反射 |
| 16 | × | 全反射必须光密→光疏；空气→玻璃永远不会 |
| 17 | × | 是薄膜**干涉**；衍射的例子是泊松亮斑 |
| 18 | × | 偏振证明光是**横波**（华附卷题 1 原型） |
| 19 | √ | $\Delta x=\dfrac{L}{d}\lambda$ |
| 20 | × | 蓝光 λ 短 → Δx 小 → 条纹变**窄**（数变多） |

### B. 填空题

| 题 | 答案 |
|----|------|
| 21 | $2\pi\sqrt{\dfrac{l}{g}}$ |
| 22 | $\lambda f = \dfrac{\lambda}{T}$ |
| 23 | $\dfrac{\sin i}{\sin r}$；$\dfrac{c}{v}$ |
| 24 | $\dfrac{1}{n}$ |
| 25 | 光从光密介质射向光疏介质；入射角大于临界角 |
| 26 | $\dfrac{L}{d}\lambda$ |
| 27 | $n\lambda$；$(2n+1)\dfrac{\lambda}{2}$ |
| 28 | 单缝；双缝 |
| 29 | 大；小；小 |
| 30 | $n-1$ |

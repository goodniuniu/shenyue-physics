## 章节路线（后续逐步建卡）

- 必修三：静电场 ✅（本轮建卡）→ 电路及其应用 → 电磁场与电磁波初步
- 选择性必修一：动量守恒定律 ✅ → 机械振动 ✅ → 机械波 ✅ → 光 ✅（本轮按四校真题补齐）
- 选择性必修二：磁场中的力与运动 → 电磁感应 → 交变电流 → 传感器
- 选择性必修三：热学 → 原子物理 → 原子核
- 高三：必修一/二/三系统复习 + 广东卷真题专题

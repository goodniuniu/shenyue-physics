## 核心内容

### 核心公式

```
折射定律：n = sin i / sin r  （i 为空气侧角度，r 为介质侧角度）
折射率：n = c/v             （光在介质中速度 v = c/n，变小）
全反射临界角：sin C = 1/n    （光从介质射向空气，i > C 时全反射）
```

### 关键概念

- **折射率与频率**：同一介质中，频率越高的光（紫 > 红）折射率越大 → 偏折越厉害、速度越小、临界角越小**越容易发生全反射**。这是色散比较题的万能链条：

$$f\uparrow \Rightarrow n\uparrow \Rightarrow v\downarrow,\ \sin C\downarrow$$

- **色散**：复色光入射介质，折射角不同而分开（华附卷题 3：比较 a、b 两光的频率、速度、临界角，全用上面链条）。

### 方法步骤：几何光学计算题通法（华附题 13 泳池灯、铁一题 13 光学元件）

1. **画光路**：在界面处画**法线**，标出入射角/折射角（角度一律相对法线）。
2. **列方程**：每个界面写一次折射定律；有"恰好全反射"字样就写 $\sin C = 1/n$ 且入射角 $= C$。
3. **几何关系**：用三角形边角关系（圆、菱形、棱镜角度）把角与边连起来——本类题的真正难点在**平面几何**。
4. 求时间：$t = \dfrac{\text{光程}}{v} = \dfrac{n\cdot s}{c}$（介质中每段都要乘 n）。

### 典型结论

- 水中点光源照出水面：出水区域是以光源正上方为圆心的**圆**，半径 $r = h\tan C$（华附题 13 泳池灯原型）。
- 平行玻璃砖：出射光与入射光**平行但侧移**；半圆玻璃砖沿半径方向入射**不偏折**。
- 三棱镜：光向**底边**偏折；紫光偏折大于红光。

### 记忆口诀

> "空气侧角大，介质侧角小；频率高者 n 大，临界角小先全反。"

## 🗣️ 费曼讲解（讲给零基础的人听）

光从空气进水，就像小车从水泥地冲进沙地：一侧轮子先变慢，车头就拐了弯——这就是折射。弯多少由"折射率"说了算，紫光比红光"更怕慢"，所以拐得更狠（色散）。全反射则是光在介质里往空气跑时，角度太"平"，一头撞在界面上被弹回来——角度超过临界角就出不去，光纤就靠这个把光关在里头。

## 📝 解题示范（一道典型题完整流程）

> 题（华附卷题 13 原型）：泳池水深 $h=2\,\text{m}$，水的折射率 $n=\dfrac{4}{3}$，池底有一点光源。求有光射出的水面区域半径。

1. 全反射临界角：$\sin C = \dfrac{1}{n} = \dfrac{3}{4}$。
2. 由 $\sin C=\dfrac{3}{4}$ 得 $\cos C=\dfrac{\sqrt7}{4}$，$\tan C=\dfrac{3}{\sqrt7}$。
3. 几何关系：出水区域半径 $r = h\tan C = 2\times\dfrac{3}{\sqrt7} = \dfrac{6}{\sqrt7} \approx 2.27\,\text{m}$。
4. 面积 $S = \pi r^2 = \dfrac{36\pi}{7} \approx 16.2\,\text{m}^2$。
5. **检验**：n 越大临界角越小、出水圆越小——物理直觉一致 ✅

## 备注

- 全反射两条件缺一不可：①光密→光疏（介质→空气）；②入射角 > 临界角。从空气射入玻璃永远不会全反射。

## 核心内容

### 关键概念
- **动量** $p = mv$：矢量，方向与速度相同；描述"运动状态的量"。
- **冲量** $I = Ft$：矢量，方向与恒力 $F$ 相同；描述"力在时间上的积累效果"。
- **动量变化量** $\Delta p = p' - p$：矢量差，必须用平行四边形定则或正交分解计算，**不能直接算数值差**。

### 核心公式/定理
```
动量定理：I_合 = F_合·t = Δp = mv' − mv
```
> 适用条件：普遍适用（恒力、变力均可；变力时用平均力或微元思想）。
> 注意事项：$F$ 必须是**合外力**；式中各量必须相对同一参考系、取统一正方向。

### 方法步骤（用动量定理解题的通法）
1. 选对象：明确研究对象（单个物体优先用动量定理）。
2. 受力分析：画出全过程所有外力，求合冲量。
3. 定正方向：规定正方向，把各速度、冲量带上正负号。
4. 列式：$F_合 t = mv' - mv$，代入求解。

### 两个高频拓展
- **流体冲击类**（水柱/风/粒子流冲击面板）：取很短时间 $\Delta t$ 内冲击的流体为研究对象，用动量定理求平均作用力 $F = \dfrac{\Delta m \cdot \Delta v}{\Delta t}$，常配合密度 $\rho$、横截面积 $S$、速度 $v$ 表示 $\Delta m = \rho S v \Delta t$。
- **全过程法**：曲线运动、多过程问题可对全程列动量定理，省去中间细节。

### 记忆口诀/技巧
> 动量定理管"一段时间"，动能定理管"一段位移"；求时间优先想动量定理，求位移优先想动能定理。

## 🗣️ 费曼讲解（讲给零基础的人听）

动量就是"撞过来有多难挡"：卡车慢吞吞也比摩托车飞驰难挡，因为它重。冲量就是"推一把推了多久"：安全气囊把人撞上去的时间拉长，同样的"难挡程度"被分摊到更长时间，人受到的力就小了。而动量定理说的是最朴素的一件事：**推多久 × 用多大劲 = 难挡程度改变了多少**——和攒钱一模一样，每天存一点，余额就变一点。唯一要警惕的是：动量有方向，往左和往右要记正负。

## 📝 解题示范（一道典型题完整流程）

> 题（二中卷题 2 原型）：蹦极者质量 $m=60\,\text{kg}$，自由下落 $t_1=2\,\text{s}$ 后绳恰好伸直，再经 $t_2=1\,\text{s}$ 到最低点。求这 1 秒内绳对人的平均作用力（$g=10\,\text{m/s}^2$）。

1. 绳伸直瞬间速度：$v = gt_1 = 20\,\text{m/s}$（向下）。
2. 对 $t_2$ 过程用动量定理（取向上为正）：$(\bar{F} - mg)t_2 = 0 - (-mv) = mv$。
3. $\bar{F} = mg + \dfrac{mv}{t_2} = 600 + \dfrac{60\times20}{1} = 1800\,\text{N}$。
4. **检验**：平均绳力必须大于重力（否则人停不下来），1800 > 600 ✅

**关键提醒**：列动量定理时 $F$ 是**合外力**——重力的冲量不能漏，这是本题最大的坑。

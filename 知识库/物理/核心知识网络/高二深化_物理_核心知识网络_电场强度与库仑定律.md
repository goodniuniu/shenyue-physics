## 核心内容

### 关键概念

- **元电荷**：$e = 1.6\times10^{-19}\ \text{C}$，是电荷量的最小单位，**不是**某个粒子；任何带电体电荷量都是 $e$ 的整数倍（密立根油滴实验测定）。
- **点电荷**：理想化模型，当带电体大小远小于间距时可视为点电荷。
- **电场强度**：描述电场本身的性质，与试探电荷无关。

### 核心公式

```
库仑定律：F = k·q₁q₂/r²  （k = 9.0×10⁹ N·m²/C²，真空、点电荷）
场强定义式：E = F/q      （q 是试探电荷，任意电场适用）
点电荷场强：E = kQ/r²    （Q 是场源电荷，仅点电荷适用）
```

> 适用条件：库仑定律与 $E=kQ/r^2$ 只适用于**真空中点电荷**；$E=F/q$ 普适。
> 注意事项：三个公式中 $q$ 与 $Q$ 的角色完全不同——这是月考选择题最爱考的坑（执信卷题 1、华附卷题 2 均考）。

### 方法步骤：场强叠加问题

1. 各场源电荷单独产生的场强分别计算（矢量，带方向）。
2. 按平行四边形/正交分解合成。
3. 对称结构（正多边形顶点放等量电荷）先看**对称性**，很多分量直接抵消（华附卷题 9 正四面体、执信卷题 8 双四棱锥均考对称叠加）。

### 静电感应与接触起电

- 感应起电：近端感应异种电荷、远端同种；导体接地则远端电荷被导走。
- 完全相同金属球接触后：**电荷先中和再平分**（二中卷题 8、执信卷题 2 均考）。

### 记忆口诀

> "定义式里 q 是客，点电荷式 Q 是主；接触平分先中和，感应近异远同处。"

## 🗣️ 费曼讲解（讲给零基础的人听）

想象电荷是一颗小球，电场是一座看不见的山坡：**电场强度**就是山坡的陡度——坡越陡，球被推得越狠；**库仑定律**说的是两个带电小球隔空互推，力气随距离变近而急剧变大（距离减半，力气变四倍）。两个一模一样的小球碰一下再分开，电量会"先互相抵消、剩下的平均分"——就像两杯不同水量的水倒进同一个壶再均分。

## 📝 解题示范（一道典型题完整流程）

> 题（执信卷题 2 原型）：两个相同金属球 A、B 分别带 $+q$ 和 $+3q$，相距 $r$ 时库仑力为 $F$。接触后放回原位，库仑力变为多少？

1. 接触前：$F = k\dfrac{q\cdot 3q}{r^2} = \dfrac{3kq^2}{r^2}$。
2. 接触平分：同种电荷直接均分，各带 $\dfrac{q+3q}{2} = 2q$。
3. 接触后：$F' = k\dfrac{2q\cdot 2q}{r^2} = \dfrac{4kq^2}{r^2} = \dfrac{4}{3}F$。
4. **检验**：电荷越"均匀"乘积越大（和定积最大），力应变大——合理 ✅

## 备注

- 电场线性质：起于正电荷（或无穷远）、止于负电荷（或无穷远），疏密表大小、切线表方向、沿电场线电势降低。电场线不是电荷的运动轨迹（除非初速为零且电场线为直线）。

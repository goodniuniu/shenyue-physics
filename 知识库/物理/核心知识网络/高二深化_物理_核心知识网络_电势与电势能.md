## 核心内容

### 关键概念（用"山坡"类比一次记牢）

| 物理量 | 类比 | 要点 |
|--------|------|------|
| 电势 $\varphi$ | 海拔高度 | 电场本身的属性，与放不放电荷无关；沿电场线方向降低 |
| 电势差 $U_{AB}=\varphi_A-\varphi_B$ | 高度差 | 与零势点选取无关 |
| 电势能 $E_p = q\varphi$ | 物体的重力势能 | 属于"电荷+电场"系统；**有正负**，$q$ 带符号代入 |
| 电场力做功 $W_{AB}=qU_{AB}$ | 重力做功 | 只与始末位置有关，与路径无关 |

### 核心公式

```
φ = E_p/q          （电势定义式，E_p、q 均带符号）
U_AB = W_AB/q      （电势差定义式）
W_AB = -ΔE_p = E_pA - E_pB   （电场力做正功，电势能减小）
E = U/d            （仅匀强电场，d 为沿场强方向的距离）
```

> 注意事项：所有公式中 $q$、$W$、$U$ 都要**带正负号**运算，这是本章计算题第一大失分点（华附卷题 14 四问连考）。

### 方法步骤：判断电势能/动能变化（华附卷题 5、题 10 类型）

1. 判断电场力方向（正电荷顺 E、负电荷逆 E）。
2. 看电场力做正功还是负功：正功 → 电势能减、动能增（仅电场力时）。
3. 能量守恒兜底：只有电场力做功时 $E_k + E_p$ = 常量。

### φ-x 图像与等势面

- $\varphi\text{-}x$ 图像**斜率的负值 = 场强** $E_x$；斜率绝对值大处场强大。
- 等势面：与电场线处处垂直；沿等势面移动电荷电场力不做功；匀强电场的等差等势面间距相等。
- 找等势点 → 连线得等势线 → 作垂线得电场线方向（华附卷题 4 菱形、题 7 圆形区域均用此法）。

### 记忆口诀

> "电势像海拔，顺线往下压；负电反着看，势能 qφ 乘；做功看首尾，正负别落下。"

## 🗣️ 费曼讲解（讲给零基础的人听）

电势就是"海拔高度"，电势差就是"高度差"，电场力做功就是"搬石头上下山"。搬石头做多少功，只取决于起点和终点的高度差，跟你走哪条山路无关——电场力做功也一样，只看首尾电势差。唯一的"妖"是负电荷：它是一块会往天上飘的石头，海拔越高，它的"势能"反而越小。所以一切公式里 $q$ 都要带符号。

## 📝 解题示范（一道典型题完整流程）

> 题（华附卷题 14 原型）：把 $q=+2\times10^{-8}\,\text{C}$ 的电荷从无穷远移到电场中 P 点，克服电场力做功 $2\times10^{-6}\,\text{J}$。求 P 点电势；若在 P 点放 $q'=-1\times10^{-8}\,\text{C}$ 的电荷，其电势能是多少？

1. "克服电场力做功"→ 电场力做功 $W = -2\times10^{-6}\,\text{J}$，电势能**增加** $2\times10^{-6}\,\text{J}$。
2. 无穷远为零势点：$E_{pP} = 2\times10^{-6}\,\text{J}$。
3. $\varphi_P = \dfrac{E_{pP}}{q} = \dfrac{2\times10^{-6}}{2\times10^{-8}} = 100\,\text{V}$。
4. 负电荷：$E_p' = q'\varphi_P = (-1\times10^{-8})\times 100 = -1\times10^{-6}\,\text{J}$（**负号必须带**）。
5. **检验**：负电荷在正电势处电势能为负——与"负电荷的石头往上飘"一致 ✅

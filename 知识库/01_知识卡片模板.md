# 知识卡片模板（v2 · 学-讲-练-复盘闭环）

> 所有新知识卡片按本模板编写。v2 在原版"核心内容"基础上新增三个板块，让每张卡片覆盖完整学习闭环：
> **核心内容（学）→ 费曼讲解（讲）→ 解题示范（练）→ 复盘要点（复盘）**。

```markdown
# 【卡片标题】知识点的精准命名

| 字段 | 内容 |
|------|------|
| **来源** | 教材章节 / 真题年份 / 试卷类型 / 题号 |
| **时间标签** | #高一筑基 / #高二深化 / #高三冲刺 |
| **难度** | ★☆☆☆☆ ~ ★★★★★ |
| **状态** | ✅已掌握 / ⚠️待强化 / ❌未理解 |

---

## 核心内容

（提炼后的干货：关键概念、核心公式、方法步骤、记忆口诀。）

## 🗣️ 费曼讲解（讲给零基础的人听）

（用生活类比把本卡最核心的 1-2 个概念讲明白。写这段的标准：
申悦能照着把家长讲懂。避免公式，多用画面。）

## 📝 解题示范（一道典型题完整流程）

> 题：（优先选已入库真题的原型题，标注来源）

1. 第一步……
2. 第二步……
3. **检验**：……（用物理直觉或守恒量校验答案，养成检验习惯）

## ✅ 复盘要点（自测清单，能讲清即打勾）

- [ ] （4-6 条可自测的具体能力点，写"能默写/能讲清/会判断"而不是"理解/掌握"）

---

## 关联卡片

- [关联卡片](相对路径) — 关联说明

---

## 备注

（踩坑记录：日期+题号；个人理解；与学校老师的差异点。）
```

## 各板块的用法（什么时候看哪段）

| 场景 | 看哪段 | 怎么用 |
|------|--------|--------|
| 第一次学 | 核心内容 | 配合教材过概念，公式自己推一遍 |
| 晚间回讲 | 🗣️ 费曼讲解 | 合上书讲给家长听，卡壳处记入备注 |
| 做题卡壳 | 📝 解题示范 | 对照示范找"我卡在第几步"，而不是直接看答案 |
| 每周复盘 | ✅ 复盘要点 | 逐条自测打勾，全勾 → 状态升 ✅；卡 2 条以上 → 保持 ⚠️/❌ |
| 考前 10 分钟 | 复盘要点 + 陷阱卡 | 只看清单，不做新题 |
| 碎片时间 | 打印版 | 每页右下角打印按钮，A4 一张纸一张卡，随身带 |

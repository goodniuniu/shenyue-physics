# 申悦学习 · AI 指导物理学习

从中秋假期（2026.9.25–27）备战高二第一次月考开始，用结构化知识库陪伴申悦到 2028 年高考的物理学习项目。

**运作模式**：每逢长假设计一期"专项复习计划"（诊断→主攻→模拟→复盘），平时用知识库做常态化碎片复习。专项没用完的卡片和真题回流储备池，下期直接调用。

## 网站内容（发布到 GitHub Pages）

- **首页**：项目导览与时间线
- **中秋 3 天辅导计划（v3 定稿）**：真题诊断 → 静电场主线突破 → 真题模拟与错题复盘（月考范围已确认为广州四校真题范围）
- **长假专项复习设计框架**：小长假/长假专项的通用设计模板，国庆专项将按此生成
- **家长物理速成指南**：静电场篇（优先）+ 动量篇，写给很久没碰物理的家长
- **物理知识库**：静电场 5 卡 + 动量 5 卡 + 光学 2 卡 + 振动波 1 卡 + 四校真题分析报告 + 亲子沟通方法卡 + 知识掌握状态表（常态化学习资源储备）
- **卡片结构**：每张卡 = 核心内容（学）+ 费曼讲解（讲）+ 解题示范（练）+ 复盘要点（复盘），每页可一键打印，适合碎片化复习

## 日常维护（每次更新内容只需三步）

1. 修改对应的 Markdown 文件（或直接让 AI 把错题"入库物理"）
2. 运行 `python build_site.py` 重新生成 `docs/`
3. 提交并推送到 GitHub，网站自动更新

```
npm install   # 首次
npm run dev   # 打开 http://localhost:7100
```

【机械振动与机械波】

核心内容

一、简谐运动

  • 回复力 $F = -kx$（弹簧振子）；单摆小角度下 $F = -\dfrac{mg}{l}x$。
  • 单摆周期 $T = 2\pi\sqrt{\dfrac{l}{g}}$（与振幅、摆球质量无关）。
  • 运动特征：平衡位置速度最大、加速度为零；最大位移处反之。从平衡位置向最大位移运动：回复力、加速度增大，速度减小。

二、振动图像 vs 波动图像（最经典的混淆点）

振动图像（x-t） 波动图像（y-x）
横轴 时间 t 位置 x
看对象 一个质点的一生 一群质点的一瞬（照片）
读周期/波长 读周期 T 读波长 λ
判方向 看下一时刻位置（斜率） "上下坡法"：沿传播方向，上坡点向下振、下坡点向上振
  • 联系两图的公式：$v = \dfrac{\lambda}{T} = \lambda f$。

三、波形图题通法（铁一题 4/9/14）

  1. 由传播方向 + 上下坡法判断各质点振动方向。
  2. 由 $\lambda$（图上读）和 $v$（题给）算 $T=\lambda/v$。
  3. "求某质点路程"：经过 $n$ 个周期路程 = $4nA$；不足整周期要看起振位置。
  4. 波的多解性：两点间距离不足一个波长时也可能相差 $(n+\tfrac{1}{4})\lambda$ 等——题 14 浮标题"水平距离的所有可能值"就是这类。

四、波的干涉、衍射、多普勒（铁一题 5/6/9/10）

  • 干涉（两相干波源叠加）：到两波源路程差 $\delta = n\lambda$ → 加强点；$\delta = (2n+1)\dfrac{\lambda}{2}$ → 减弱点。加强点振幅 = $A_1+A_2$，减弱点 = $|A_1-A_2|$；加强/减弱位置固定不随时间变（题 5D 正是考这个）。
  • 明显衍射条件：障碍物/孔的尺寸与波长相当或更小。
  • 多普勒：波源靠近观察者 → 接收频率变高；远离 → 变低。
  • 受迫振动与共振：受迫振动频率 = 驱动力频率；驱动力频率 = 固有频率时振幅最大（共振）。减振（大棚阻尼器，题 10）要避开共振。

🗣️ 费曼讲解（讲给零基础的人听）

振动图像是"一个人的日记"：记录同一个质点每天的起伏；波动图像是"全班的大合影"：定格某一瞬间所有人的位置。看日记（x-t 图）判断下一步往哪走，看曲线斜率就行；看合影（y-x 图）判断每个人下一步怎么动，要用"上下坡法"——顺着波的传播方向走，上坡的人要往下坐，下坡的人要往上爬。波则是把"振动"这个动作一传十、十传百地传出去，每个质点只在原地上下动，并不跟着波跑。

📝 解题示范（一道典型题完整流程）

题（铁一卷题 9 原型）：一列横波沿 x 轴正方向传播，波形图上读得 $\lambda=4,\text{m}$，波速 $v=2,\text{m/s}$。求周期，并求平衡位置处质点在 $3,\text{s}$ 内通过的路程（振幅 $A=5,\text{cm}$）。

  1. $T = \dfrac{\lambda}{v} = \dfrac{4}{2} = 2,\text{s}$。
  2. $t = 3,\text{s} = \dfrac{3}{2}T$ → 路程 $= \dfrac{3}{2}\times 4A = 6A = 30,\text{cm}$。
  3. 检验："整周期数 × 4A"规则，半周期对应 2A，1.5 周期即 6A ✅

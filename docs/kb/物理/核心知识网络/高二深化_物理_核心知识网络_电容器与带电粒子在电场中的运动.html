【电容器与带电粒子在电场中的运动】

字段 内容
来源 人教版必修三第十章；2025.10 执信卷题 6/10/12/14/15、华附卷题 15
时间标签 #高二深化
难度 ★★★★☆
状态 ❌未理解

核心内容

一、电容器

C = Q/U                    （定义式，C 与 Q、U 无关）
C = ε_rS/(4πkd)            （平行板电容器决定式）
E = U/d                    （板间匀强电场）

两类动态分析（执信卷题 6 压力传感器原型）：

情形 不变量 分析链
始终接电源 U 不变 d↓→C↑→Q↑；E=U/d 随 d 变
充电后断开 Q 不变 d↓→C↑→U↓；而 $E=\dfrac{4\pi kQ}{\varepsilon_r S}$ 与 d 无关，只随 S、ε_r 变

二、电容器充放电实验（执信卷题 12）

  • $i\text{-}t$ 图线与坐标轴围成的面积 = 电荷量 Q；改变 R 只改变充放电快慢，面积（总电荷量）不变。
  • 充电：电流从最大值指数衰减到 0；放电电流方向相反。

三、带电粒子在电场中的加速与偏转（示波器模型，执信卷题 10 原模型）

加速（电压 $U_1$）：

$$qU_1 = \frac{1}{2}mv_0^2 ;\Rightarrow; v_0=\sqrt{\frac{2qU_1}{m}}$$

偏转（电压 $U_2$、板长 $l$、板距 $d$）——类平抛运动：

$$y = \frac{1}{2}at^2 = \frac{qU_2 l^2}{2mdv_0^2} = \frac{U_2 l^2}{4U_1 d},\qquad \tan\theta = \frac{v_y}{v_0} = \frac{U_2 l}{2U_1 d}$$

关键结论：偏转角 $\tan\theta$ 与偏转量 $y$ 与 q、m 无关（只取决于电压和几何）——执信卷题 10 的核心考点。 常用技巧：偏转后速度的反向延长线过板中央水平中点（类平抛推论）。

四、月考压轴风格：电场 + 多过程综合

执信卷题 15（多区域电场 + 圆周运动）、题 14（弹簧 + 电场 + 圆弧轨道）、华附卷题 15（库仑力 + 弹簧 + 摩擦）的共同套路：

  1. 分过程：每换一种受力情况画一条分界线。
  2. 每个过程选工具：匀变速 → 牛顿定律或动能定理；只看始末 → 动能定理优先。
  3. 电场力做功计入动能定理：$W_{电} + W_{摩} + W_{弹} + \cdots = \Delta E_k$。

🗣️ 费曼讲解（讲给零基础的人听）

电容器就是一个"存电的水桶"：电量 Q 是水量，电压 U 是水位差，电容 C 是桶的粗细。接着电源等于水龙头开着——水位差被死死按住不变；断开电源等于关了龙头——水量不变，水位差随桶形变化。带电粒子偏转则是"先弹弓后平抛"：先被加速电压像弹弓一样射出去，再进偏转电场走一个标准的平抛曲线。

📝 解题示范（一道典型题完整流程）

题（执信卷题 10 原型）：加速电压 $U_1=200,\text{V}$，偏转电压 $U_2=50,\text{V}$，板长 $l=4,\text{cm}$，板距 $d=2,\text{cm}$。求偏转角正切，并判断换用不同比荷的粒子偏转角是否改变。

  1. 直接套结论：$\tan\theta = \dfrac{U_2 l}{2U_1 d} = \dfrac{50\times 0.04}{2\times 200\times 0.02} = \dfrac{2}{8} = 0.25$。
  2. 公式里没有 $q$、$m$ → 偏转角与粒子种类无关。
  3. 但射出动能 $E_k = qU_1 + qE\cdot y$ 含 $q$ → 电荷量不同的粒子动能不同。
  4. 检验："偏转角相同、动能未必相同"正是该题正确选项的组合逻辑 ✅

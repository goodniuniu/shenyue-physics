【动量守恒定律】知识点的精准命名

字段 内容
来源 人教版选择性必修一 第一章 第3~4节
时间标签 #高二深化
难度 ★★★☆☆
状态 ⚠️待强化

核心内容

关键概念

  • 相互作用的物体组成的系统，在合外力冲量为零时，总动量保持不变。
  • 动量守恒是矢量式，比牛顿定律更适用于短暂、作用力复杂的过程（碰撞、爆炸、反冲）。

核心公式/定理

守恒条件：系统所受合外力为零（ΣF_外 = 0）
表达式：m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′

适用条件的三个层次（由严到宽）：

  1. 系统合外力为零 → 全过程守恒；
  2. 内力 ≫ 外力（碰撞、爆炸瞬间）→ 该瞬间守恒；
  3. 某方向合外力为零 → 该方向上动量守恒（分方向列式）。 注意事项：所有速度必须相对同一参考系（通常取地面）；先规定正方向再代入正负号。

方法步骤

  1. 选系统：把发生相互作用的物体圈成一个系统。
  2. 查外力：判断守恒条件是否满足（不满足时改用动量定理或牛顿第二定律）。
  3. 定方向、设正方向。
  4. 列守恒式 + 必要的过程方程（能量、运动学）联立求解。
  5. 检验：结果是否合理（速度方向、大小量级）。

与机械能守恒的辨析（考试必考易混点）

对比项 动量守恒 机械能守恒
守恒量 矢量（有方向） 标量
条件 合外力为零 只有重力/弹力做功
碰撞中 总是守恒 弹性碰撞才守恒
典型不守恒情形 系统受外力（如粗糙地面上含滑块的系统受摩擦力） 完全非弹性碰撞（动能损失最大）

记忆口诀/技巧

"动量看外力，能量看功"；碰撞问题先写动量守恒，再写能量关系定碰撞类型。

🗣️ 费曼讲解（讲给零基础的人听）

冰面上两个人互相推开：原本都不动，推完后一个向左一个向右，"难挡程度"一正一负加起来还是零——这就是动量守恒。它的意思是：一家人（系统）内部的推推搡搡，改变不了这个家的总账。什么时候总账会变？只有"外人"（合外力）插手的时候。所以用守恒之前先问一句：我把谁圈进了系统？外力真的为零吗？

📝 解题示范（一道典型题完整流程）

题（二中卷题 3 原型简化）：光滑水平面上，人（$m=20,\text{kg}$）从静止的车（$M=80,\text{kg}$）上以 $0.5,\text{m/s}$（对地）向右走下，求车的速度。

  1. 系统（人+车）水平方向不受外力 → 动量守恒，初动量为零。
  2. 设向右为正：$0 = m v_人 + M v_车$。
  3. $v_车 = -\dfrac{m}{M}v_人 = -\dfrac{20}{80}\times 0.5 = -0.125,\text{m/s}$（向左）。
  4. 检验：人右行则车左退，方向相反、动量等大——合理 ✅

  • "人船模型"本质是系统初动量为零时的平均动量守恒：$m_1 \bar{v}_1 = m_2 \bar{v}_2$，进一步得 $m_1 x_1 = m_2 x_2$（位移均相对地面）。

【静电平衡与静电屏蔽】

核心内容

一、静电平衡是怎么形成的

外电场把导体里的自由电子"推"到一侧 → 两侧积累正负感应电荷 → 感应电荷产生附加电场，与外电场方向相反 → 附加电场不断增强，直到与外电场完全抵消 → 自由电荷不再定向移动，达到静电平衡。

二、静电平衡四大特点（选择题必考）

# 特点 常见错误说法
1 导体内部合场强处处为零（外电场 + 感应电场叠加为零） "内部没有电场" ❌（是两个电场抵消，不是不存在）
2 净电荷只分布在外表面；越尖锐处密度越大，凹陷处几乎没有 "内部没有电荷" ❌（是没有净电荷，自由电子仍在无规则运动）
3 表面电场线与表面垂直 不垂直 → 电荷会继续移动，还没平衡
4 整个导体是等势体，表面是等势面 "电势一定为零" ❌（等势 ≠ 为零）

三、静电屏蔽两种方式

目的 做法 是否要接地
屏蔽外电场对内部的影响 空腔导体（金属网罩、铁皮房）包裹 不需要接地
屏蔽内部带电体对外界的影响 空腔导体包围 + 接地 必须接地

实例：金属鸟笼里鸟安然无恙（屏蔽外场）；高压带电作业服掺金属丝；输电线上方接地导线防雷击。

四、尖端放电

电荷在尖端密度最大 → 尖端附近场强极强 → 空气被电离放电。避雷针利用尖端放电（顶端是尖的，不是球形的）；高压设备电极做成球形则是避免尖端放电。

记忆口诀

"内场为零靠抵消，净电荷在外跑；等势不等零，尖端密度高；挡外不接地，挡内要接地。"

🗣️ 费曼讲解（讲给零基础的人听）

把导体想象成一屋子人，外电场是一阵从左边刮来的风。一开始人都被吹到右边墙根（感应电荷），但挤在墙根的人会往回推（附加电场），直到"往回推的劲"和"风力"一样大，大家就站稳不动了——这就是静电平衡。这时候屋里（导体内部）一点风都没有，所以金属屋子能给人挡风雨：这就是静电屏蔽。注意是"风力被顶住了"，不是"风不存在"。

📝 解题示范（一道典型题完整流程）

题（讲义题 46 原型）：枕形导体放在负点电荷 $Q$ 的电场中达到静电平衡。下列说法正确的是？ A. 导体两端电势不等 B. 用导线连接两端，连接瞬间无电流 C. 导体中心场强为 $\dfrac{kQ}{R^2}$ D. 感应电荷在中心产生的场强方向指向 Q

  1. 静电平衡 → 导体是等势体 → 两端电势相等，A ❌；等势则无电势差 → 导线接通瞬间无电流，B ✅。
  2. 内部合场强为零，C ❌（$\dfrac{kQ}{R^2}$ 只是外电场的，忘了感应电场）。
  3. 感应电场与外电场等大反向 → 方向应背离 Q 一侧，D ❌。
  4. 答案：B。检验：等势体、合场强为零、感应场抵消外场——三大特点全部用上 ✅

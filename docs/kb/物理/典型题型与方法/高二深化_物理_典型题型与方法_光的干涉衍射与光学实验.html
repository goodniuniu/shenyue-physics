一、现象辨析（选择题第一题最爱考，一张表搞定）

现象 本质 生活实例
干涉 两列相干光叠加 肥皂膜彩色条纹、增透膜、双缝干涉
衍射 光绕过障碍物 圆盘阴影中心亮斑（泊松亮斑）、单缝条纹
偏振 光是横波的证明 3D 电影眼镜、偏振太阳镜
色散 n 随频率变 彩虹、棱镜分光
全反射 光密→光疏超临界角 水中气泡特别亮、光导纤维、海市蜃楼（沙漠/海面全反射）
多普勒效应 波源与观察者相对运动 卫星信号频率变化、救护车音调变化

易错对照（铁一题 1/6、华附题 1 的错误选项来源）：肥皂膜彩色 = 干涉（不是衍射）；增透膜 = 干涉（不是偏振）；3D 眼镜 = 偏振（不是色散）；水中气泡亮 = 全反射（不是干涉）；偏振证明光是横波（不是纵波）。

二、双缝干涉测波长（华附题 12、铁一题 11）

$$\Delta x = \frac{L}{d}\lambda \quad\Rightarrow\quad \lambda = \frac{d,\Delta x}{L}$$

  • 器材顺序（光源后）：滤光片 → 单缝 → 双缝 → 光屏。
  • 条纹：等间距明暗相间；条纹与双缝平行方向分布（与缝平行排列）。
  • 换蓝光（λ 变短）→ Δx 变小 → 屏上条纹数增多。
  • 测量：$n$ 条亮纹间隔数 = $n-1$，$\Delta x = \dfrac{x_n - x_1}{n-1}$；少数间隔数会导致 λ 测量值偏大。
  • 干涉条件：两光源频率相同、相位差恒定（普通光源需先过单缝；激光相干性好可直接照双缝）。

三、测玻璃折射率（插针法，华附题 11、铁一题 12）

  • 原理：$n = \sin i/\sin r$。
  • 没有量角器时的线段法：在法线上取对称点，作入射/折射光线的垂线段 $h_1,h_2$，则 $n = h_1/h_2$（sin 之比 = 垂线段之比）。
  • 半圆玻璃砖沿半径（法线）方向入射时不偏折，可只用 3 颗大头针。
  • 减小误差：入射角适当大些（角度测量相对误差小）；但过大则出射光弱、不易观察。

🗣️ 费曼讲解（讲给零基础的人听）

干涉就是两列整齐的水波相遇：峰撞峰的地方浪特别高（亮纹），峰撞谷的地方水面平静（暗纹），而且哪些地方亮、哪些地方暗是固定的，所以屏幕上出现稳定的条纹。条纹间距公式 $\Delta x=\dfrac{L}{d}\lambda$ 其实是相似三角形：双缝间距 d 越小、屏越远 L 越大，条纹就被"放大"得越稀——这也是为什么实验要用它反推看不见的波长。

📝 解题示范（一道典型题完整流程）

题（华附卷题 12 原型）：双缝间距 $d=0.2,\text{mm}$，双缝到屏距离 $L=1,\text{m}$，测得第 1 条到第 6 条亮纹间距为 $10,\text{mm}$。求波长。

  1. 间隔数 = $6-1=5$（常见坑：直接用 6），$\Delta x = \dfrac{10}{5} = 2,\text{mm}$。
  2. $\lambda = \dfrac{d,\Delta x}{L} = \dfrac{0.2\times10^{-3}\times 2\times10^{-3}}{1} = 4\times10^{-7},\text{m} = 400,\text{nm}$。
  3. 检验：400 nm 在紫光范围，数量级合理 ✅

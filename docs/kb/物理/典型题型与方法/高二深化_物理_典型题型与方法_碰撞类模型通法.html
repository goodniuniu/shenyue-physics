【碰撞类模型通法】知识点的精准命名

字段 内容
来源 人教版选择性必修一 第一章 第5节 + 历年月考/高考真题归纳
时间标签 #高二深化
难度 ★★★★☆

核心内容

一、碰撞的"三原则"（判据，选择题常考）

任何碰撞必须同时满足：

  1. 动量守恒：$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$
  2. 动能不增：$E_{k前} \geq E_{k后}$（弹性碰撞取等号）
  3. 速度合理：
    • 同向碰撞后，前面物体的速度 ≥ 后面物体的速度（否则二次碰撞）；
    • 碰前靠近，碰后分离。

用途：判断四个选项中"哪个碰撞结果可能"，逐一用三条检验。

二、弹性碰撞结论公式（务必熟记或会推导）

两球弹性碰撞（动量 + 动能双守恒）：

v₁′ = [(m₁−m₂)v₁ + 2m₂v₂] / (m₁+m₂)
v₂′ = [(m₂−m₁)v₂ + 2m₁v₁] / (m₁+m₂)

特例（考试秒杀点）：

  • $m_1 = m_2$：交换速度；
  • $m_2 \gg m_1$ 且 $v_2=0$：轻者原速反弹（如乒乓球撞墙）；
  • $m_1 \gg m_2$：重者速度几乎不变，轻者近 2v₁ 弹出。

三、完全非弹性碰撞

碰后共速 $v' = \dfrac{m_1v_1+m_2v_2}{m_1+m_2}$。 动能损失最大： $$\Delta E_k = \frac{1}{2}\cdot\frac{m_1 m_2}{m_1+m_2}\cdot v_{相对}^2$$ （$v_{相对}$ 为碰前相对速度；$\dfrac{m_1m_2}{m_1+m_2}$ 叫约化质量/折合质量。）

四、解题通法（计算题四步走）

  1. 写动量：守恒式列上（注意正负号）。
  2. 写能量：按碰撞类型写动能关系（弹性：相等；完全非弹性：损失公式）。
  3. 解方程：弹性碰撞直接用结论公式最快。
  4. 检验三原则：特别是"不二次碰撞"。

五、类碰撞模型（识别特征）

  • 子弹射入木块（瞬间动量守恒 + 之后摩擦生热）；
  • 物块滑上小车/滑板；
  • 小球与摆球的相互作用。

记忆口诀/技巧

"一守恒、二不增、三合理"；弹性背公式，非弹性用损失公式。

🗣️ 费曼讲解（讲给零基础的人听）

碰撞就像结账：不管两辆车撞成什么样，"动量"这笔总账必须平；而"动能"这笔钱只能花掉（变成热和变形），绝不能变多。所以判断一个碰撞结果对不对，就像会计查账：先查总账平不平（动量守恒），再查钱有没有凭空多出来（动能不增），最后看看合不合常理（后面的车不能比前面的还快，不然还得再撞一次）。

📝 解题示范（一道典型题完整流程）

题（二中卷题 6 原型）：质量 $m_1=1,\text{kg}$ 的小车以 $v_1=3,\text{m/s}$ 与静止的 $m_2=2,\text{kg}$ 小车发生弹性碰撞，求碰后两车速度。

  1. 套弹性碰撞结论：$v_1' = \dfrac{(m_1-m_2)v_1}{m_1+m_2} = \dfrac{(1-2)\times3}{3} = -1,\text{m/s}$（反弹）。
  2. $v_2' = \dfrac{2m_1v_1}{m_1+m_2} = \dfrac{2\times1\times3}{3} = 2,\text{m/s}$。
  3. 检验三原则：动量 $1\times3 = 1\times(-1)+2\times2 = 3$ ✅；动能 $\frac12\times1\times9 = \frac12\times1\times1 + \frac12\times2\times4 = 4.5$ ✅；轻撞重被弹回，无二次碰撞 ✅

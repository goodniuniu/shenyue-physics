"恰好"翻译字典（本学期版）

题目关键词 立即翻译成 章节
恰好发生全反射 入射角 $i = C$，$\sin C = \dfrac{1}{n}$ 光（华附题 6/13、铁一题 13）
恰好通过圆周最高点 支持力 $N=0$，$mg = \dfrac{mv^2}{R}$，$v=\sqrt{gR}$ 圆周（铁一题 15、二中题 15）

临界题通法

  1. 见到"恰好/刚好/至少/最多"立即停笔：把这句话单独圈出来。
  2. 查字典翻译成上面的临界方程——这就是题目的"隐藏方程"，多数临界题就缺这一个方程。
  3. 与常规方程（守恒式、牛顿第二定律）联立求解。
  4. 临界方程往往不含时间、不含质量——它是几何/状态条件，不是过程方程。

为什么压轴题都爱考"恰好"

临界条件把"范围问题"变成"等式问题"：不用解不等式组，取等号就是边界。出题人用它把两道普通题缝成一道综合题（二中题 15：弹性碰撞 + 恰好过最高点；铁一题 13：折射 + 恰好全反射）。

记忆口诀

"恰好出现笔先停，临界方程送上门；等号一取边界定，常规方程来联立。"

🗣️ 费曼讲解（讲给零基础的人听）

"恰好"是出题人的暗号，意思是"这里藏着一条免费方程"。比如"小球恰好通过最高点"，翻译过来就是"在最高点那一刻，轨道完全不推它了，只有重力拉着它转圈"——这一句话就是一个方程。不会临界题，多半不是不会物理，是没听懂这句暗号。

📝 解题示范（一道典型题完整流程）

题（铁一卷题 15 简化）：物块从高度 $h$ 滑下后进入半径 $R=0.4,\text{m}$ 的圆轨道，恰好能通过最高点。求 $h$（轨道光滑，从最低点所在的水平面起算）。

  1. 圈关键词："恰好通过最高点" → 临界方程 $v_{顶}=\sqrt{gR}=\sqrt{4}=2,\text{m/s}$。
  2. 常规方程（机械能守恒）：$mgh = mg\cdot 2R + \dfrac12 mv_{顶}^2$。
  3. 解：$h = 2R + \dfrac{R}{2} = \dfrac{5}{2}R = 1.0,\text{m}$。
  4. 检验：经典结论 $h=\frac52R$，正确 ✅

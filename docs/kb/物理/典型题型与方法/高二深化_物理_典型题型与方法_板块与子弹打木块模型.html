【板块与子弹打木块模型】知识点的精准命名

字段 内容
来源 人教版选择性必修一 第一章 + 名校月考高频题归纳
时间标签 #高二深化
难度 ★★★★☆
状态 ❌未理解

核心内容

模型总图

一个物体以速度 $v_0$ 进入/滑上另一个可动物体（木块、小车、木板），通过摩擦力/阻力相互作用。核心双主线：

  • 动量：相互作用阶段系统动量守恒（地面光滑）→ 求共同速度；
  • 能量：机械能损失转化为内能 $Q = f \cdot s_{相对}$。

一、子弹打木块（瞬间嵌入型）

动量守恒：m v₀ = (m + M) v_共
能量：Q = f·d = ½mv₀² − ½(m+M)v_共²

d 为子弹打进木块的深度（相对位移）；Q 即系统动能损失，全部转化为内能。 若木块固定在地面上：动量不守恒（墙/地对木块有外力），用动能定理 + 牛顿定律处理。

二、滑块—木板模型（地面光滑，板块间粗糙）

分两段讨论：

  1. 相对滑动阶段：滑块减速、木板加速，直到共速；
  2. 共速之后：若外力为零，二者一起匀速。

关键量：

  • 共速：$v_共 = \dfrac{m v_0}{m + M}$（动量守恒一步出）。
  • 相对位移：用能量 $f \cdot s_{相对} = \dfrac{1}{2}mv_0^2 - \dfrac{1}{2}(m+M)v_共^2$ 求。
  • 板长（恰好不滑下）：$L_{min} = s_{相对}$。

是否共速的判断：先假设共速求出需求摩擦力 $f_{需}$，与最大静摩擦 $f_{max}=\mu N$ 比较；$f_{需} \le f_{max}$ 才能共速。

三、人船模型（动量为零系统）

系统初动量为零、水平方向不受外力：

m₁ x₁ = m₂ x₂，且 x₁ + x₂ = L（相对位移）

位移必须相对地面；适合求"气球载人上升高度""人在船上走船退多远"等问题。

四、爆炸与反冲

  • 动量守恒（内力 ≫ 重力等外力）；
  • 动能增加（化学能/其他形式能转化而来）——与碰撞"动能不增"正好相反；
  • 公式：$0 = m_1 v_1 + m_2 v_2$（静止爆炸），得 $\dfrac{v_1}{v_2} = \dfrac{m_2}{m_1}$，$\dfrac{E_{k1}}{E_{k2}} = \dfrac{m_2}{m_1}$。

方法步骤

  1. 画过程图，标出各阶段速度方向；
  2. 判断守恒条件（系统、方向）；
  3. 动量守恒求共速；
  4. 能量关系求相对位移 / 内能 / 板长。

记忆口诀/技巧

"先守恒求速度，后能量求位移"；看到"相对"两个字，立刻想到 $Q = f \cdot s_{相对}$。

🗣️ 费曼讲解（讲给零基础的人听）

子弹打木块像"钉子钉进木头"：钉子（子弹）的冲劲一部分变成木头的运动，一部分变成钻进木头的深度（摩擦生热）。板块模型像"你踩着滑板往前冲"：你减速、滑板加速，直到你俩一样快就再也不相对滑了——这个"一样快"用动量守恒一步求出；你在滑板上蹭了多远，用能量（摩擦 × 相对位移）求。记住两条主线：动量管速度，能量管距离。

📝 解题示范（一道典型题完整流程）

题（二中卷题 10 原型）：质量 $M=3,\text{kg}$ 的木板静置在光滑水平面上，质量 $m=1,\text{kg}$ 的物块以 $v_0=4,\text{m/s}$ 滑上木板，$\mu=0.2$（$g=10$）。若木板足够长，求共同速度和相对滑动距离。

  1. 动量守恒：$v_共 = \dfrac{mv_0}{m+M} = \dfrac{1\times4}{4} = 1,\text{m/s}$。
  2. 能量：$Q = \mu mg\cdot s_{相对} = \dfrac12mv_0^2 - \dfrac12(m+M)v_共^2 = 8 - 2 = 6,\text{J}$。
  3. $s_{相对} = \dfrac{6}{0.2\times1\times10} = 3,\text{m}$。
  4. 检验：损失动能 6 J < 初动能 8 J，板长 ≥ 3 m 才不滑下——合理 ✅

✅ 复盘要点（自测清单，能讲清即打勾）

  • [ ] "动量求共速、能量求相对位移"双主线能脱口而出
  • [ ] 木块固定时动量不守恒（墙是外力）能讲清
  • [ ] 是否共速的判断：$f_需$ vs $f_{max}=\mu N$
  • [ ] 恰好不滑下 → $L_{min}=s_{相对}$ 的条件反射
  • [ ] 爆炸/反冲动能增加、碰撞动能不增，方向不记反

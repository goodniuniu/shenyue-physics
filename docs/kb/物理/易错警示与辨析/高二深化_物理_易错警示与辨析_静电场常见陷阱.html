【静电场常见陷阱】月考踩坑清单

字段 内容
来源 2025.10 广州四校月考真题选择题错误选项归纳
时间标签 #高二深化
难度 ★★★☆☆
状态 ❌未理解

核心内容

陷阱 1：定义式里谈"成正比/成反比"

$U=W/q$、$\varphi=E_p/q$、$E=F/q$、$C=Q/U$ 都是定义式——电场（或电容器）本身的量与放入的电荷无关。见到"$U$ 与 $W$ 成正比"直接判错。

陷阱 2：$E=kQ/r^2$ 乱用

只适用于点电荷（真空）。匀强电场不能用；选项里"它适用于匀强电场"是经典错误（华附卷题 2B）。

陷阱 3：电势高 ≠ 电势能大

$E_p = q\varphi$：负电荷在电势越高的地方电势能反而越小。判断电势能必须先看电荷正负。

陷阱 4：符号全军覆没

$W_{AB}=qU_{AB}$、$E_p=q\varphi$ 中 q、W、U 全部带符号运算。"克服电场力做功 W"意味着 $W_{电}=-W$。华附题 14、执信题 13 全靠符号拿分。

陷阱 5：电场线当轨迹

电场线一般不是带电粒子的运动轨迹；只有"初速为零 + 电场线为直线"才重合。场强大的地方电势不一定高（二者无必然联系）。

陷阱 6：等势面上乱做功

沿等势面移动电荷电场力做功为零；但跨等势面只看首尾电势差，与路径无关——"沿曲线移动做功更多"是错的（执信题 5C）。

陷阱 7：接触平分忘"先中和"

两相同金属球接触：$q'=\dfrac{q_1+q_2}{2}$（异种电荷先抵消再平分），不是简单相加也不是各拿一半绝对值。

陷阱 8：电容器"谁不变"记反

  • 接着电源 → U 不变；断开电源 → Q 不变。
  • Q 不变时板间场强 $E=\dfrac{4\pi kQ}{\varepsilon_r S}$ 与 d 无关——"拉开极板 E 变小"是错的（执信题 3D 变形）。

陷阱 9：偏转结论记串

示波器模型 $\tan\theta=\dfrac{U_2 l}{2U_1 d}$ 与 q、m 无关；但射出时的动能 $E_k=qU_1+qEy$ 与 q 有关（执信题 10D 正是考这个区别）。

陷阱 10：静电感应方向搞反

正电荷靠近导体：近端（靠近侧）感应负电荷，远端为正。"感应出同种电荷"或"电荷被创生"均错（铁一题 3、二中题 8）。

📝 解题示范（一道典型题完整流程）

题（华附卷题 2 原型改编）：下列说法正确的是？ A. $U=W/q$ 说明电势差与电场力做功成正比 B. $E=kQ/r^2$ 适用于匀强电场 C. 负电荷在电势越高的地方电势能越大 D. 沿等势面移动电荷，电场力不做功

  1. A：定义式不谈正反比 → ❌（陷阱 1）
  2. B：$kQ/r^2$ 只适用点电荷 → ❌（陷阱 2）
  3. C：$E_p=q\varphi$，q 为负则电势越高电势能越小 → ❌（陷阱 3）
  4. D：等势面上 $U=0$，$W=qU=0$ → ✅ 选 D

通法：概念辨析题每个选项都先问"它踩的是哪条陷阱"，比凭感觉快得多。

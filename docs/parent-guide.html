家长物理速成指南 · 静电场篇

写给很久没碰物理的家长：这是本项目的第二份速成指南。 依据 2025 年 10 月广州四校月考真题，静电场是这次月考最可能的主干内容，优先级高于动量篇。 老规矩，你不需要会做题。读完它，你能做到三件事：听懂她在学什么、看出作业错在哪、接住她的提问。

第 0 关：5 分钟，建立直觉

用"山坡"一次记住三个词

词 是什么 一句话直觉
电场强度 E 电场"推电荷的劲"有多大 像山坡的陡度：坡越陡，球滚得越猛；场越强，电荷受力越大
电势 φ 电场中某点的"高度" 像海拔：山顶电势高，山脚电势低；沿电场线方向电势一路下降
电势能 E_p = qφ 电荷在某点具有的"位置能量" 像山顶上的石头：海拔越高，石头势能越大——但负电荷是"倒过来的石头"，海拔越高它势能反而越小

本章第一公式

电场力做功 = 电荷量 × 电势差        （W = qU）

就像把石头从山顶搬到山脚：重力做的功 = 重量 × 高度差。电场里完全同理。

为什么孩子在这章容易栽跟头

全是符号：电荷有正负、电势差有正负、做功有正负。式子里丢一个负号，整道题就错了。所以"符号带全"是本章第一习惯，也是你检查作业的第一要点。

第 1 关：三个核心考点，各配一道你能看懂的例题

考点 1：电场力做功与电势能（计算题必考）

例：把 +2 C 的电荷从 A 点移到 B 点，电场力做了 −6 J 的功（即克服电场力做功 6 J），A、B 间电势差 U = W/q = −6 ÷ 2 = −3 V。说明 B 点电势比 A 低 3 V。

你可以这样讲给孩子听："做功除以电荷量就是电势差，跟搬石头：功 ÷ 重量 = 高度差，一个道理。负数说明是往下走。"

考点 2：电容器两条链（选择题必考）

电容器 = 存电荷的"水桶"：水量 Q、水位差 U、桶的容量 C = Q/U。

  • 接着电源 → 水龙头开着，水位差 U 不变，改变桶的宽窄（极板间距）只会改变水量。
  • 断开电源 → 水龙头关了，水量 Q 不变，拉开极板水位差会变化，但"坡的陡度 E"只取决于水量和桶底面积，和间距无关（反直觉，月考爱考）。

考点 3：带电粒子偏转（示波器模型）

粒子先在"加速电场"里被推到一定速度，再进入"偏转电场"做类平抛运动（水平匀速 + 竖直匀加速，和平抛一模一样的配方）。

核心结论：偏转角只由电压和板的几何决定，与粒子本身的电荷、质量无关——选择题见到"不同粒子偏转角不同"基本是错的。

第 2 关：不会物理也能用的"批改四问清单"（静电场版）

# 问题 看什么
1 符号带全了吗？ q、W、U 的正负号写没写；"克服电场力做功"有没有翻译成负号
2 哪个公式？ 定义式（E=F/q、C=Q/U）还是决定式（E=kQ/r²、C=εS/4πkd）——用错公式是全错
3 谁不变？ 电容器题先问"接着电源（U 不变）还是断开（Q 不变）"，答不出这步后面全白算
4 能量去哪了？ 只有电场力做功时，动能 + 电势能应该不变；两个都增大一定是错的

第 3 关：她可能问你的 4 个问题（附参考答案）

1. "电势和电势能到底有什么区别？" 电势是"这个位子海拔多高"，是电场自己的属性，不放电荷它也在；电势能是"这块石头在这个海拔有多少能量"，必须有电荷才有。关系：电势能 = 电荷量 × 电势。

2. "为什么负电荷在电势高的地方电势能反而小？" 因为电势能 = q × φ，q 是负的，φ 越大乘出来越小。就像负电荷是一块"会往上飘的石头"，海拔越高它越"没劲"。

3. "电场线是电荷跑的路线吗？" 不是。电场线只表示力的方向；电荷跑哪条线还取决于它的初速度。只有"从静止释放 + 电场线是直线"时才会沿着线跑。

4. "手机电容屏、电容话筒和电容器是一回事吗？" 原理同源：都是两个导体隔层绝缘体存电荷。考试不考应用细节，但电容器"谁不变"的动态分析必考。

电场力做功 W = qU（符号带全）     做正功 → 电势能减、动能增
